# FOSKY.J OFFICIAL — static website

A responsive, static artist website for GitHub Pages. No build step or framework is required.

## Publish on GitHub Pages
1. Open your `foskyjofficial` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder (including `favicon.svg`) from this folder. Do not upload only the ZIP.
4. Commit the upload to the `main` branch.
5. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. After GitHub finishes publishing, your site should be at `https://YOUR-GITHUB-USERNAME.github.io/foskyjofficial/`.

## Notes
- The portrait chooser only previews a photo locally on the device/browser where it is selected. It does not upload the photo to GitHub or save it for visitors.
- The Audiomack button opens `https://audiomack.com/foskyj2005`. Replace that URL in `index.html` with the exact song URL if you want the button to open the individual track.
- Contact email currently uses `sonviaofficial@gmail.com`.
